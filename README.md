# Zé Pilintra

Zé Pilintra is a 2D RPG developed in C using the Raylib graphics library. The project combines classic RPG mechanics such as combat, progression, inventory management, equipment, and enemy waves with educational logic challenges based on Mathematical Logic concepts.

The main objective is to create an engaging gameplay experience while reinforcing logical reasoning skills through interactive challenges integrated into the game progression.

## Features

### Character Progression

* Experience (XP) system
* Leveling system
* Skill points
* Character stat upgrades

  * Attack
  * Defense
  * Maximum Health

### Combat System

* Melee attacks
* Enemy collision damage
* Damage calculation based on player stats
* Debug hitbox visualization

### Inventory System

* Item collection
* Item storage
* Item selection and management
* Consumable item usage

### Equipment System

* Weapons
* Armor
* Accessories
* Equip and unequip functionality
* Stat bonuses from equipment

### Enemy System

* Multiple enemy types

  * Goblin
  * Bandit
  * Skeleton
  * Elite
* Unique attributes per enemy
* Enemy-specific loot tables

### Wave System

* Progressive enemy waves
* Wave announcements
* Difficulty scaling

### Logic Challenge System

* Mathematical Logic questions
* Tautology identification
* Contradiction identification
* Contingency identification
* XP rewards for correct answers
* Feedback for correct and incorrect responses

### Additional Features

* Fullscreen mode (F11)
* Controls panel
* God Mode for testing
* Camera system
* Drop notifications
* Equipment notifications

## Controls

| Key   | Action             |
| ----- | ------------------ |
| A / D | Move               |
| SPACE | Jump               |
| J     | Attack             |
| I     | Open Inventory     |
| E     | Open Equipment     |
| ENTER | Confirm Selection  |
| U     | Unequip Item       |
| F11   | Toggle Fullscreen  |
| H     | Show/Hide Controls |
| F10   | Toggle God Mode    |
